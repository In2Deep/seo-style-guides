# Google developer documentation style guide (local copy)

A copy of <https://developers.google.com/style> for writers and AI agents working in this repo.
Google offers its docs over MCP only with Gemini, which this project doesn't use, so this copy stands in.
Generated by `sync_google_docs.py`; don't edit anything in this folder by hand.

- Snapshot: 2026-11-05, 70 pages.
- Source: each page's Markdown, served at the page's address plus `.md.txt`, saved byte for byte.
- File names: the page's address after `/style/`, with `--` for each `/`.
- Checksums: `SHA256SUMS` holds each page's SHA-256.
- License: Google LLC, "Google developer documentation style guide". Page content is under
  [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) and code samples under
  [Apache 2.0](https://www.apache.org/licenses/LICENSE-2.0); see the
  [Google Developers Site Policies](https://developers.google.com/site-policies).
- Google's own change notes: [What's new](whats-new.md).

## Check for changes or update

```bash
python3 sync_google_docs.py --guide style          # check only; exit status 1 means the copy is out of date
python3 sync_google_docs.py --guide style --save   # update, then: git diff guides/style
cd guides/style && shasum -a 256 -c SHA256SUMS   # verify the local files
```
