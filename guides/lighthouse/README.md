# Lighthouse documentation and audits (local copy)

A copy of <https://developer.chrome.com/docs/lighthouse/overview> for writers and AI agents working in this repo.
Google offers its docs over MCP only with Gemini, which this project doesn't use, so this copy stands in.
Generated by `sync_google_docs.py`; don't edit anything in this folder by hand.

- Snapshot: 2026-11-11, 79 pages.
- Source: each page's Markdown, served at the page's address plus `.md.txt`, saved byte for byte.
- File names: the page's address after `/docs/lighthouse/`, with `--` for each `/`.
- Checksums: `SHA256SUMS` holds each page's SHA-256.

  [Google Developers Site Policies](https://developers.google.com/site-policies).
- Google's own change notes: [Lighthouse releases](https://github.com/GoogleChrome/lighthouse/releases).

## Check for changes or update

```bash
python3 sync_google_docs.py --guide lighthouse          # check only; exit status 1 means the copy is out of date
python3 sync_google_docs.py --guide lighthouse --save   # update, then: git diff guides/lighthouse
cd guides/lighthouse && shasum -a 256 -c SHA256SUMS   # verify the local files
```
