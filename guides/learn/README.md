# web.dev Learn courses: performance, images, accessibility, HTML, forms and responsive design (local copy)

A copy of <https://web.dev/learn> for writers and AI agents working in this repo.
Google offers its docs over MCP only with Gemini, which this project doesn't use, so this copy stands in.
Generated by `sync_google_docs.py`; don't edit anything in this folder by hand.

- Snapshot: 2026-11-21, 120 pages.
- Source: each page's Markdown, served at the page's address plus `.md.txt`, saved byte for byte.
- File names: the page's address after `/learn/`, with `--` for each `/`.
- Checksums: `SHA256SUMS` holds each page's SHA-256.

  [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) and code samples under
  [Apache 2.0](https://www.apache.org/licenses/LICENSE-2.0); see the
  [Google Developers Site Policies](https://developers.google.com/site-policies).
- Google's own change notes: none published; web.dev keeps no change list for its courses.

## Check for changes or update

```bash
python3 sync_google_docs.py --guide learn          # check only; exit status 1 means the copy is out of date
python3 sync_google_docs.py --guide learn --save   # update, then: git diff guides/learn

```
